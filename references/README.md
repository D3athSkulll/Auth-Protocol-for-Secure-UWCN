# References

Place the base paper this protocol/evaluation model is derived from here as
`base-paper.pdf`. It is intentionally not included in this repository (no
source PDF was provided alongside the original code), but every module that
carries over a specific figure from the paper (e.g. the 296-bit/message and
211 ms reference values in `uwcn.evaluation.paper_metrics`, and the
`Ref [21]`-`Ref [25]` comparison table in `uwcn.config.COMPARISON`) says so
in its docstring/comments so it can be cross-checked against the source
once it is added here.
